# Phase 3 I01 parametric-bootstrap evidence

Date: 2026-09-15

## Scope completed

- Exact response refitting through the original block or sparse backend without
  rebuilding or reinterpreting the accepted design.
- Unconditional simulation with new random effects and weighted residuals, and
  explicit conditional simulation with fitted random effects held fixed.
- Replicate- and purpose-separated `PCG64DXSM` streams, with RNG and NumPy
  identity recorded and no cross-version identity claim.
- Bounded serial/parallel refits with native thread limiting and exact
  worker-count invariance for the locked assessment.
- Atomic private ledgers containing canonical metadata and non-pickle response
  arrays, including integrity, fit, source, plan, resource, resume, and exclusive
  writer checks. An empty manifest is committed before the first refit.
- Complete outcome classification; singular fits remain usable, failures are
  not redrawn, and exact one-sided failure-rate bounds are available.
- Percentile/basic descriptive intervals using the documented NumPy linear
  quantile convention and fail-closed incomplete behavior.

Prediction-only `.kamino` bundles still omit responses and cannot refit or
bootstrap. A private ledger requires the same live or reproducibly reconstructed
fit and is deliberately not a hidden full-model artifact.
